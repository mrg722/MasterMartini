# Master Martini

Proyecto móvil para la asignatura Desarrollo de Aplicaciones Móviles (DSY1105), basado en el caso de Master Martini Chile SPA.

La idea es reunir recetas, videos y cursos técnicos para el rubro gastronómico, con una interfaz clara y fácil de usar.

## Tecnologías

- Kotlin
- Jetpack Compose y Material 3
- MVVM
- Almacenamiento local

## Estado

Proyecto en desarrollo. La estructura inicial está preparada y se irá completando por etapas.
